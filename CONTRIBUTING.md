# Contributing

Thanks for looking. This repository is a public mirror of our internal repo. Our engineers work there, and the `strathlume-oss-sync` app publishes the branches here, so commits show the Strathlume author but are pushed by the bot.

Because changes flow one way, from internal to public, we can't take pull requests on GitHub, and issues are switched off. You are welcome to fork the code under the MIT licence.

If you find a security problem, please follow [SECURITY.md](SECURITY.md).
